## Setup project (Block 1)
### Setup GitHub
To check which GitHib-Accounts are already logged in on the device and whsch one's active, use the command `gh auth status`.
To change the active GitHib-Account use the command `git auth switch --user "[username]"`
To change the Username which will be the author from your future commits, use the command `git config user.name "[username]"` 
To clone the remote repository which already exists in GutHub user the command `git clone https://github.com/username/repository-name.git`
Once your within the git directory you can also change the user-email with the command `git config user.email "[email]"`
`git config user.name` and `git config user.email` is completely seperate to the gh-account you're logged in

### Setup Proect Architecture
To setup the project architecture directly via the terminal, the following commands are of great importance:
* `Get-Location` (`pwd`): Returns the current path
* `Set-Location` (`cd`): Navigate to a specific path. To return in an path by one step use `cd..`
* `Get-ChildItem` (`gci`): Returns the contents of the current folder
* `New-Item -ItemType Directory "[directoryname]"` (`mkdir`): Creates a new directory at the specified destination
* `New-Item -ItemType File "[filename]"` (`ni`): Creates a new file at the specified destination

### New Learnings
* Working directory: This means the current path in your terminal. Commands without an complete path refer to this directory.
* Absolute path: The absolute path specifies the full path from the drive to the destination
* Relative path: The relative path specifies the path starting from to the current path
* Switching directories: To switch directories via the terminal use the command `cd [destination]`

## Virtual environment for python (Block 2)
In order you can have various python projects and not be forced to maintain the same versions for all projects, you have to setup a virtual environment for each of the projects. To setup the virtual environment use the command `python -m venv .venv`. If this command was accidently exercuted in the wrong path you can just delete the .venv-directory after executing `deactivate` in the terminal if the virtual environment was already activated.

In order that the project accesses this virtual environment and not refers to the global environment you have to activate it every time you start a new terminal session as it remains only in the RAAM. To activate the virtual environment use the command  `.venv\Scripts\Activate.ps1`.

To check the current version of python you have installed on your PC use the command `python --version`. If an error occures it means python isn't installed on the device.

To create a python-file use the ending .py. You can execute the file via the terminal, for example: `python src/main.py`.

## First Python Exercise (Block 3)
### Task: File and Folder Analyzer

Write a program that:

1. Stores a folder path in a variable.
2. Finds all direct contents of that folder.
3. Outputs only files.
4. Displays the name and size of each file.

Use `pathlib` wherever possible.

##### Example Output

text
README.md - 1.2 KB
main.py - 430 Bytes
data.json - 2.8 KB


### Python pathlib – Basic Methods

| Methode oder Eigenschaft | Bedeutung                           |
| ------------------------ | ----------------------------------- |
| `Path.cwd()`             | Aktuelles Arbeitsverzeichnis        |
| `Path.home()`            | Benutzerverzeichnis                 |
| `path.name`              | Datei- oder Ordnername              |
| `path.parent`            | Übergeordnetes Verzeichnis          |
| `path.exists()`          | Prüft, ob der Pfad existiert        |
| `path.is_file()`         | Prüft, ob der Pfad eine Datei ist   |
| `path.is_dir()`          | Prüft, ob der Pfad ein Ordner ist   |
| `path.iterdir()`         | Gibt direkte Ordnerinhalte zurück   |
| `path.glob()`            | Sucht nach einem Muster             |
| `path.stat().st_size`    | Gibt die Dateigröße in Bytes zurück |
| `path.mkdir()`           | Erstellt einen Ordner               |
| `path.touch()`           | Erstellt eine leere Datei           |
| `path.read_text()`       | Liest eine Textdatei                |
| `path.write_text()`      | Schreibt eine Textdatei             |
| `path.unlink()`          | Löscht eine Datei                   |
